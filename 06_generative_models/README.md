# Generative models
This module introduces generative models, the foundation behind most "AI" products and features since ChatGPT's public release in November 2022. It begins with the core concept: models that shape something out of pure noise, using patterns learned from huge amounts of training data. It then shows how prompting can reshape the output without retraining the model itself. From there, the module turns to a broader question: what happens if AI-generated content increasingly populates future training data, and what this means alongside the automation of entry-level jobs. It closes with a hands-on style-transfer demo.
